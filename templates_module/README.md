# Templates Module

This directory contains HTML templates for all UI components rendered by Flask.

## Structure

- `base.html`: Base layout for all templates.
- `auth/`: Login and registration pages.
- `client/`: Client-facing pages.
- `provider/`: Pages for providers including dashboard, service editing, and photo wizard.

Each page uses Jinja2 blocks and is styled to integrate with Tailwind/Bootstrap or custom CSS.
